# Telegram Voice-to-Text Companion

Персональный сервис для Telegram, который отслеживает только ваши исходящие голосовые сообщения и автоматически отправляет следом нормализованную текстовую версию в тот же чат.

## Что делает сервис

- Работает как Telegram user client через Telethon, поэтому сообщение с расшифровкой отправляется от вашего имени.
- Реагирует только на исходящие voice messages и игнорирует входящие голосовые и обычные текстовые сообщения.
- Скачивает аудио во временную папку, отправляет его в OpenAI для транскрибации, нормализует текст и удаляет локальный аудиофайл после обработки.
- Хранит обработанные `chat_id` и `message_id` в SQLite, чтобы перезапуски не создавали дубли.
- Обрабатывает сообщения одного чата последовательно, чтобы несколько голосовых подряд получали текст в правильном порядке.
- Не отправляет технические ошибки собеседнику: проблемы попадают только в логи и локальную таблицу статусов.

## Локальный запуск

1. Получите `TELEGRAM_API_ID` и `TELEGRAM_API_HASH` на <https://my.telegram.org>.
2. Скопируйте `.env.example` в `.env` и заполните значения.
3. Установите зависимости и запустите сервис:

```bash
python -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
PYTHONPATH=src python -m tg_voice_assistant.app
```

При первом запуске Telethon попросит авторизоваться в Telegram. После этого session-файл сохранится в `data/session*`.

## Деплой на сервер

1. Скопируйте репозиторий на сервер.
2. Создайте `.env` по примеру `.env.example`.
3. Если Telegram-сессии ещё нет, выполните первый запуск интерактивно на сервере или скопируйте локальные файлы `data/session*`.
4. Запустите сервис:

```bash
docker compose up -d --build
```

Логи доступны через:

```bash
docker compose logs -f tg-voice-assistant
```

## Ограничения безопасности

Это персональный user client, поэтому храните `.env` и `data/session*` как секреты. Не коммитьте их в репозиторий и не передавайте третьим лицам.
